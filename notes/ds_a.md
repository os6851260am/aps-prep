## 1. ADT: Abstract Data Structure
Interface and Implement

### Queue
- FIFO
- Operations: Enqueue, Dequeue, Size, Peek
- Implement: Linked List or Array

### Stack
- LIFO
- Operation: POP, PUSH, Size, Peek
- Implement: Linked List or Array

### Set
- Uniqueness

### Question:
Q1: What is ADT and how's it different to Data Structure?
- ADT focuse on external interface and Data Structure focuse on internal implement e.g. Linked List and Array

Q2: ADT examples and their rules
- Queue: FIFO (First-in, First-out), is used in BFS algorithm. 
- Stack: LIFO (Last-in, First-out), is used in DFS algorithm.
- Set: Unique items. There would not be duplicates items in Set.
